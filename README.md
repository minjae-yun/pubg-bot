# 치킨로그 — PUBG 스쿼드 결산·킬내기 디스코드 봇

PUBG PC/Steam 전적을 검색하고, 디스코드 친구들과 함께한 플레이를 MVP·킬왕·딜량왕·버스충으로 결산하는 봇입니다.

## 현재 기능

- PUBG 닉네임으로 평생 전적 검색
- 솔로/듀오/스쿼드와 FPP/TPP 모드 선택
- 승리, Top 10, 킬, K/D, 평균 딜량 등을 Discord Embed로 표시
- 디스코드 사용자와 PUBG 닉네임 연결
- 파티 참가 버튼과 최대 10명의 파티 세션
- 파티 시작 이후 함께 플레이한 경기 자동 수집
- 일반 파티와 별도로 2대2·3대3·4대4·2대2대2 킬내기 진행
- 킬내기 종료 경기의 킬·사망·치킨을 Google 점수판에 자동 입력
- 경기 기록 없이 현재 파티를 종료하는 파티 취소 명령과 버튼
- 팀 기록, MVP, 킬왕, 딜량왕, 생존왕 자동 결산
- 등록 정보와 파티 기록을 SQLite에 영구 저장
- 사녹 결산 경기의 착지·이동·사망·자기장 데이터를 학습용으로 수집
- 같은 닉네임의 결과를 기본 2분간 캐싱
- 원하는 디스코드 채널에서만 명령어를 허용하는 선택 설정

## 1. 필요한 계정과 키 준비

### Discord

1. [Discord Developer Portal](https://discord.com/developers/applications)에서 `New Application`을 누릅니다.
2. `Bot` 메뉴에서 봇을 만들고 토큰을 발급받습니다.
3. `Installation` 메뉴에서 Guild Install에 `applications.commands`와 `bot`을 추가합니다.
4. 봇 권한으로 `View Channels`, `Send Messages`, `Embed Links`를 허용하고 테스트 서버에 설치합니다.

이 봇은 메시지 내용을 읽지 않으므로 Privileged Gateway Intents를 켤 필요가 없습니다.

### PUBG

1. [PUBG Developer Portal](https://developer.pubg.com/)에서 로그인합니다.
2. 개인 앱을 등록하고 무료 PUBG API 키를 발급받습니다.

Discord 토큰과 PUBG API 키는 다른 사람에게 보내거나 Git에 올리면 안 됩니다.

## 2. 프로젝트 설치

Node.js 22.5 이상이 필요합니다. PowerShell에서 이 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
npm install
Copy-Item .env.example .env
```

`.env` 파일을 열어 다음 네 값을 입력합니다.

```env
DISCORD_TOKEN=Discord Bot Token
DISCORD_CLIENT_ID=Discord Application ID
DISCORD_GUILD_ID=테스트 서버 ID
PUBG_API_KEY=PUBG API Key
```

디스코드 ID를 복사하려면 디스코드의 `사용자 설정 → 고급 → 개발자 모드`를 켭니다. 그 후 서버 아이콘을 우클릭하여 서버 ID를 복사할 수 있습니다.

## 3. 명령어 등록 및 실행

테스트 서버에 `/전적` 명령어를 등록합니다.

```powershell
npm run register
```

봇을 실행합니다.

```powershell
npm start
```

터미널에 `치킨로그 봇이 준비되었습니다.`가 나타나면 디스코드에서 실행합니다.

```text
/전적 닉네임:PLAYER_NAME 모드:스쿼드 FPP
```

## 파티 결산 사용 순서

파티에 참가할 사람은 최초 한 번 자신의 PUBG 닉네임을 등록합니다. `이름`은 선택 항목이며, 입력하면 킬내기 시트에는 PUBG 닉네임 대신 해당 이름이 표시됩니다.

```text
/등록 닉네임:PLAYER_NAME 이름:민재
```

표시 이름은 같은 명령어를 다시 실행해 언제든 바꿀 수 있습니다. 기존 Discord 사용자 ID, PUBG 계정 ID와 이전 파티·경기 기록은 유지되며, `이름`을 생략해 다시 등록해도 이미 저장된 표시 이름은 지워지지 않습니다. 변경한 이름은 이후 새로 시작하는 킬내기에 적용됩니다.

파티장이 게임을 시작하기 전에 아래 명령어를 실행합니다.

```text
/파티시작
```

함께 플레이할 친구들은 생성된 메시지의 `파티 참가` 버튼을 누릅니다. 모든 참가자는 먼저 `/등록`을 완료해야 합니다.

PUBG 플레이를 마친 뒤 파티장이 `결산하기` 버튼을 누르거나 아래 명령어를 실행합니다.

```text
/파티결산
```

파티 시작 이후 참가자 중 2명 이상이 함께 플레이한 매치를 찾아 팀 기록과 MVP를 보여줍니다. PUBG API에 새 경기가 반영되기까지 시간이 걸릴 수 있으므로, 경기를 찾지 못하면 잠시 기다렸다가 다시 결산하면 됩니다.

경기 없이 파티를 끝내거나 결산할 경기가 없을 때는 파티장이 `파티 취소` 버튼을 누르거나 아래 명령어를 실행합니다.

```text
/파티취소
```

파티장 또는 서버 관리자만 파티를 결산하거나 취소할 수 있습니다. 취소 후에는 같은 채널에서 바로 새 파티를 시작할 수 있습니다.

등록 정보와 파티 세션은 기본적으로 `data/bot.sqlite`에 저장됩니다. 이 파일은 공개 저장소에 올리지 않는 것이 좋습니다.

## 킬내기 Google 시트 연결

킬내기 명령어를 사용하기 전에 최초 한 번만 Google 서비스 계정을 연결합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들거나 기존 프로젝트를 선택합니다.
2. `API 및 서비스 → 라이브러리`에서 **Google Sheets API**를 사용 설정합니다.
3. `IAM 및 관리자 → 서비스 계정`에서 서비스 계정을 만듭니다.
4. 해당 서비스 계정의 `키 → 키 추가 → 새 키 만들기 → JSON`을 눌러 키 파일을 받습니다.
5. 프로젝트에 `secrets` 폴더를 만들고 받은 파일명을 `google-service-account.json`으로 바꿔 넣습니다.
6. JSON 파일의 `client_email` 주소를 복사합니다.
7. 킬내기 Google 시트의 **공유** 버튼을 눌러 그 이메일을 **편집자**로 추가합니다.
8. `.env`에 다음 값을 추가합니다.

```env
KILL_RACE_SHEET_ID=구글_시트_URL의_d와_edit_사이_ID
KILL_RACE_SHEET_URL=구글_시트_전체_URL
GOOGLE_SERVICE_ACCOUNT_KEY_PATH=secrets/google-service-account.json
KILL_RACE_AUTO_REFRESH_SECONDS=60
```

예를 들어 주소가 `https://docs.google.com/spreadsheets/d/ABC123/edit`이면 Sheet ID는 `ABC123`입니다. `KILL_RACE_SHEET_URL`은 비워도 되지만 입력하면 디스코드의 **점수판 열기** 버튼이 해당 주소를 사용합니다.

서비스 계정 JSON, `.env`, `data/`는 Git에 올리지 않습니다. `secrets/`는 `.gitignore`에 등록되어 있습니다.

자동 입력은 배포한 킬내기 시트의 다음 탭 이름과 칸 배치를 사용합니다. 탭 이름은 바꾸지 마세요.

- `2팀 점수판`, `2팀 입력`: 2대2·3대3·4대4
- `3팀 점수판`, `3팀 입력`: 2대2대2
- 한 킬내기에서 팀당 최대 20경기까지 기록

## 킬내기 사용 순서

참가자 전원이 먼저 자신의 실제 플레이 계정을 등록합니다.

```text
/등록 닉네임:PLAYER_NAME 이름:민재
```

개설자가 첫 경기를 시작하기 전에 킬내기를 만듭니다. 목표 점수를 생략하면 30점입니다.

```text
/킬내기시작 모드:3대3 목표점수:30
```

개설자는 자동으로 TEAM A에 들어갑니다. 나머지 참가자는 생성된 카드에서 **TEAM A 참가** 또는 **TEAM B 참가**를 누릅니다. 2대2대2에서는 TEAM C 버튼도 나타납니다. 다른 팀 버튼을 누르면 출발 전까지 팀을 옮길 수 있습니다.

모든 자리가 찬 뒤 개설자가 **킬내기 출발**을 누릅니다. 이때 현재까지의 PUBG 경기 목록을 기준선으로 저장하고, Google 시트의 이전 입력값을 지운 뒤 팀과 선수 이름을 자동으로 넣습니다. 반드시 첫 경기에 들어가기 전에 출발을 누르세요.

점수 규칙은 다음과 같습니다.

- 참가 버튼을 누른 순서대로 위에서부터 1티어, 2티어, 3티어, 4티어로 배치
- 1티어 확정 처치: 1킬당 `+1점`
- 2티어 확정 처치: 1킬당 `+2점`
- 3티어 확정 처치: 1킬당 `+3점`
- 4티어 확정 처치: 1킬당 `+4점`
- 경기 종료 시 최종 사망 상태: `-1점`
- 블루칩으로 살아나 최종 생존하면 사망 기록을 `0`으로 초기화
- 블루칩 부활 후 다시 사망해 최종 사망 상태라면 `-1점`
- 치킨 경기: 중간 사망 여부와 관계없이 팀원 전원 사망 감점 없음
- 치킨: 팀 점수 `+8점`
- 팀킬: 킬 점수에 포함하지 않음
- 기절: 점수에 포함하지 않음

봇은 기본 60초마다 PUBG API에 새로 끝난 경기가 있는지 확인합니다. 경기가 API에 게시되면 팀별 다음 라운드 행에 킬, 사망, 치킨을 기록하고 시트 수식이 점수를 갱신합니다. 같은 매치 ID는 SQLite에 기록되므로 여러 번 확인해도 중복 합산되지 않습니다.

디스코드 카드의 **지금 갱신**을 누르면 즉시 한 번 더 확인하고, **점수판 열기**를 누르면 Google 시트가 열립니다. 명령어로도 현재 저장된 점수를 볼 수 있습니다.

```text
/킬내기현황
```

마지막 경기가 시트에 반영된 것을 확인한 뒤 개설자가 **킬내기 종료**를 누르거나 아래 명령어를 실행합니다.

```text
/킬내기종료
```

공식 PUBG API는 진행 중인 경기의 킬을 제공하지 않습니다. 따라서 인게임 1초 단위 실시간 점수판이 아니라, **경기 종료 후 API에 결과가 올라온 시점**에 자동 반영됩니다. 마지막 판이 바로 보이지 않으면 잠시 기다린 뒤 **지금 갱신**을 누르세요.

일반 파티 결산과 킬내기는 별개입니다. 같은 날 `/파티시작`과 `/킬내기시작`을 모두 사용해도 되고, 킬내기를 하지 않는 날에는 기존 파티 기능만 사용하면 됩니다.

## 사녹·태이고 학습 데이터 수집

파티 결산 초안을 만들거나 새로고침할 때, 함께 플레이한 경기 중 사녹(`Savage_Main`)과 태이고(`Tiger_Main`) 경기를 자동으로 수집합니다.

- 정리된 데이터: `data/bot.sqlite`
- 사녹 원본 텔레메트리: `data/telemetry/Savage_Main/*.json.gz`
- 태이고 원본 텔레메트리: `data/telemetry/Tiger_Main/*.json.gz`
- 수집 항목: 참가자 최종 전적, 최초 착지, 파티원 이동 좌표, 사망/킬 사건, 자기장 변화
- 같은 경기를 다시 새로고침해도 한 경기로 갱신되며 중복 누적되지 않음
- `결산 확정`을 누른 경기만 학습에 사용할 수 있도록 확정 상태를 별도로 기록

저장 폴더는 `.env`의 `TELEMETRY_ARCHIVE_PATH`로 바꿀 수 있습니다. `data/`는 Git에 올라가지 않으므로 운영 전에는 SQLite 파일과 텔레메트리 폴더의 별도 백업 방법을 준비해야 합니다.

현재 단계는 데이터 수집까지이며, 승률 예측이나 자동 피드백 모델은 아직 실행하지 않습니다. 이후 모델 관련 코드는 `ml/`에 봇 코드와 분리해서 추가합니다.

터미널을 닫거나 컴퓨터를 끄면 봇도 오프라인이 됩니다. 개발이 끝난 뒤 같은 프로젝트를 클라우드 서버에 배포하면 24시간 실행할 수 있습니다.

## 특정 채널에서만 사용하기

디스코드 채널을 우클릭해 채널 ID를 복사하고 `.env`에 입력합니다.

```env
ALLOWED_CHANNEL_ID=채널_ID
```

비워두면 서버의 모든 채널에서 사용할 수 있습니다.

## 실제 운영 서버로 옮기기

테스트가 끝난 뒤 봇을 운영 서버에 초대하고 해당 서버 ID를 `DISCORD_GUILD_ID`에 입력한 다음 `npm run register`를 다시 실행하면 됩니다.

여러 서버에서 공용으로 사용할 단계가 되면 아래 값을 변경하고 명령어를 한 번 더 등록합니다.

```env
REGISTER_GLOBALLY=true
```

전역 명령어는 디스코드에 반영되는 데 시간이 걸릴 수 있습니다.

## 자주 발생하는 문제

- `/전적`이 보이지 않음: `npm run register`를 실행했는지, `DISCORD_GUILD_ID`가 맞는지 확인합니다.
- 봇이 오프라인임: `npm start`가 실행 중인지 확인합니다.
- PUBG 인증 오류: `PUBG_API_KEY` 앞뒤에 공백이 없는지 확인합니다.
- 파티에 참가할 수 없음: 해당 서버에서 `/등록`을 먼저 실행했는지 확인합니다.
- 결산할 경기가 없음: 파티 시작 이후 실제로 함께 플레이했는지 확인하고 API 반영을 잠시 기다립니다.
- 경기 없이 파티를 종료하고 싶음: 파티장 또는 서버 관리자가 `/파티취소`를 실행합니다.
- 닉네임을 못 찾음: 현재 기본 플랫폼은 PC/Steam이며 PUBG Mobile은 공식 API에서 지원하지 않습니다.
- 요청 제한 오류: 개발용 PUBG 키의 기본 제한은 분당 10회입니다. 잠시 기다린 뒤 다시 시도합니다.
- `/킬내기시작`에서 시트 설정 오류가 남: Google Sheets API 사용 설정, 서비스 계정 JSON 경로, 시트 편집자 공유를 확인합니다.
- 킬내기 마지막 경기가 안 보임: PUBG API 게시를 기다린 뒤 `지금 갱신`을 누릅니다.
- 실행할 때 SQLite 실험 기능 경고가 보임: Node.js 내장 SQLite 안내이며 봇 실행에는 영향을 주지 않습니다.
