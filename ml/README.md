# 사녹 머신러닝 작업 공간

이 폴더는 충분한 사녹 경기 데이터가 모인 뒤 분석과 모델 학습 코드를 두는 곳입니다. Discord 봇 실행 코드와 학습 코드를 분리해, 모델 실험이 봇 운영에 영향을 주지 않도록 합니다.

예정된 순서는 다음과 같습니다.

1. 확정된 파티 경기만 SQLite에서 추출
2. 착지 위치, 첫 교전 시점, 자기장 이동, 팀 간격, 생존 시간 등의 학습 특성 생성
3. 치킨 여부와 순위를 목표값으로 한 기본 모델 학습
4. 데이터 누수를 검사하고 새 경기로 성능 검증
5. 검증된 결과만 Discord 자동 피드백에 연결

원본 데이터와 학습 결과물은 용량과 개인정보 문제 때문에 Git에 올리지 않습니다.
